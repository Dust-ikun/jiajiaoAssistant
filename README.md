# 家教单助手

把微信家教群里的聊天记录**粘进来**，自动拆成一条条单子、抽出地址/科目/薪水/教员要求，折算成可比较的时薪，判断「我接不接得了」，再按通勤 / 时薪 / 时效排序。

纯本地运行：单子、资质、高德 key 都只在本机，不上传任何服务器。

## 解决什么问题

家教群里找一个能接的单，要同时对付四件事：

| 痛点 | 群里的实际样子 | 这个工具怎么做 |
| --- | --- | --- |
| **好单被抢** | 一条消息里塞 3~4 单，还在聊天记录里不停被顶走 | 粘一段文本就按编号拆成多条；每条标「几小时前」，超过 24 小时变红（这种基本已被接掉） |
| **薪水没法比** | `130/h`、`3000元/月`、`150一节课（1.5小时）`、`一本100/92研究生110-120` 混在一起 | 全部折算成 **元/小时** 再排序；月薪按 `周次 × 单次时长 × 4.33` 折，区间与分档一律取下限 |
| **能不能接要逐条核对** | 985/211、研究生、男/女老师、有辅导经验、特定专业…… 一条条看太慢 | 你的资质只填一次，逐单判「可接 / 存疑 / 不可接」；信息不全或有软条件一律落**存疑**，宁可多看一眼也不漏单 |
| **通勤全靠猜** | 地址只写「XX地铁站附近」，去一趟到底多久不知道 | 高德公交路径规划算通勤，给出多套换乘方案（含步行、换乘次数、票价），默认按通勤最短排序 |

## 主要功能

- **粘贴即拆单**：一条消息里多个单子按编号自动切块，支持 6 种真实群格式（`#1138`、`广州线下: ZX2201#新单`、`🏄 susu2610501`、`110512号家教`、`ZXGZ20261103.2`、`家教编号: xxx`）
- **字段抽取**：地址 / 区 / 商圈 / 学段 / 年级 / 科目 / 人数 / 性别 / 授课形式 / 频次 / 单次时长 / 薪水（含分档）/ 教员要求；抽不到的留空并标记，绝不编造
- **时薪折算**：把时薪、按次、按天、月薪统一成元/小时，支持 `120/2小时`、`200-240/2h`、`一节课150（1.5小时）`、`3000元/月`
- **资质匹配**：学校层次、学历、性别、专业、证书、经验；「要求有经验」默认放行（可关）
- **通勤**：高德公交/地铁多方案，按下一个工作日早高峰算；配额、失败原因、算不出的单子都看得见
- **分类视图**：「通勤算不出」单独一栏，点进去照样能看详情、改状态、复制原文，方便去补地址
- **重复导入自动合并**：同一单被多群转发只记一次，并显示「转发 N 次」

## Windows 快速开始

### 方式一：安装包（推荐）

1. 打开 [Releases](../../releases)，下载 `jiajiao-setup-*.exe`
2. 双击安装。没做代码签名，Windows 会弹「已保护你的电脑」→ 点**更多信息** → **仍要运行**
3. 开始菜单搜「家教单助手」打开

### 方式二：免安装版

下载 `jiajiao-portable-*.exe`，放在任意目录双击即可，不写注册表。

### 首次使用三步

1. **设置 → 出发点**：填你从哪出发（必须有，通勤不会猜你的起点）
2. **粘贴导入**：在微信里选中群消息复制，整段粘进来 → 「开始识别」
3. **设置 → 我的资质**：学校层次、学历、性别、专业、证书 —— 判定全靠它

> 不填出发点也能用，只是通勤一列显示「未配置」，列表只能按时薪 / 时效排。
> 不填资质则所有单子都会判「存疑」。

### 配置高德 key（可选）

不算通勤就不用配。要算的话：

1. 到[高德开放平台](https://lbs.amap.com/)申请一个**Web 服务**类型的 key
2. 编辑 `%APPDATA%\jiajiao\.env`（首次启动会自动生成这个模板）

```ini
AMAP_KEY=你的key
AMAP_DAILY_LIMIT=2000
```

一单最多消耗 2 次调用（地理编码 + 路径规划），默认每天 2000 次（≈ 一次灌完上千单历史单）。同一地址会被缓存复用，命中缓存不扣次数。

### 数据存在哪

| 内容 | 位置 |
| --- | --- |
| 单子与通勤结果 | `%APPDATA%\jiajiao\data\jiajiao.db` |
| 我的资质 | `%APPDATA%\jiajiao\data\profile.json` |
| 高德 key 与配额 | `%APPDATA%\jiajiao\.env` |

卸载程序不会删这些文件；要彻底清空就手动删掉 `%APPDATA%\jiajiao`。

## 从源码运行

要求 **Windows + Node 24 及以上**（依赖内置的 `node:sqlite`，不需要装数据库）。

```bash
npm install
npm run dev
```

后端起在 `8787`，前端 Vite 起在 `5173`，浏览器打开 <http://localhost:5173> 即可。

只想跑后端（服务端会托管 `web/dist`）：

```bash
npm run build
npm -w server run start
# 打开 http://127.0.0.1:8787
```

### 自己打包安装包

国内网络必须先设镜像，否则 Electron / NSIS 的二进制从 GitHub 拉不动：

```bat
set "ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/"
set "ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/"
npm run package
```

产物在 `desktop/release/`：`jiajiao-setup-<version>.exe`（安装版）与 `jiajiao-portable-<version>.exe`（免安装）。

## 开发

```bash
npm test            # 解析 / 判定 / 存储 / 通勤 / 接口 全量回归（不联网、不消耗高德配额）
npm run test:e2e    # Playwright 截图（用临时库，不含真实单子）
npm run test:desktop # Electron 壳冒烟测试
```

- 解析层是**纯函数、零 IO**，测试样本在 `server/src/parser/samples/`
- 存储用 Node 内置 `node:sqlite`，**不引 better-sqlite3**
- 通勤测试全部使用假 provider，真 key 只用于手动冒烟

## 技术栈

| 层 | 选型 |
| --- | --- |
| 后端 | Node 24 + TypeScript（原生剥类型）、Express、`node:sqlite` |
| 前端 | React 18 + Vite + Tailwind CSS |
| 桌面壳 | Electron（精确锁版本）+ electron-builder（NSIS / Portable） |
| 外部依赖 | 高德 Web 服务 API（仅通勤，可选） |

## 隐私说明

- 所有单子、资质、地址只写本机 SQLite，**不上传服务器**
- 仓库里不含 `data/`、`.env`、安装包与任何真实单子数据（见 `.gitignore`）
- 运行日志对手机号做打码，不记录单子正文

## 已知限制

- 只做**粘贴**导入（复制群里的一段消息，粘进导入框并选群），不 hook 微信进程、也不监听剪贴板 —— 避开封号与合规风险，也避免把读不到群名的单子混进库
- 未购买代码签名，SmartScreen 首次运行会拦一次
- 高德免费额度有限，地址写得过于笼统（或一条地址里塞了整段招生文案）会算不出通勤
- 只针对广州等已内置区域词典的城市做了优化，其他城市能跑但区域识别会偏弱
